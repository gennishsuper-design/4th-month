# Контрольная работа: Веб-приложение «ToDoApp»

## 🎯 Цель работы
Разработать веб-приложение для управления списком задач с использованием Django. 
Закрепить навыки работы с:
* Функциональными контроллерами (FBV).
* Связями между моделями (`ForeignKey`).
* Формами Django (`forms.Form` или `forms.ModelForm`).
* Базовым Django ORM.

---

## 🛠 Технические требования

### 1. Структура проекта
* Приложение должно быть построено строго на базе **Function-Based Views (FBV)**.
* Обработка пользовательского ввода и валидация данных при создании/редактировании должны выполняться через **Django Forms**.

---

### 2. Модели данных

В `models.py` необходимо реализовать две модели со связью **Один-ко-многим** (`ForeignKey`):

1. **`Category` (Категория задач)**
   * `name` — название категории (строка, ограничение по длине, уникальное значение, например: *"Учеба"*, *"Работа"*, *"Личное"*).

2. **`Task` (Задача)**
   * `title` — название задачи (строка, ограничение по длине, обязательное).
   * `description` — описание задачи (текстовое поле, может быть пустым).
   * `category` — **внешний ключ (`ForeignKey`)**, ссылающийся на модель `Category` (при удалении категории задачи должны удаляться или категория сбрасываться).
   * `is_completed` — статус выполнения (булево значение, по умолчанию `False`).
   * `created_at` — дата и время создания (заполняется автоматически).

---

### 3. Требуемый функционал (CRUD)

Вам необходимо реализовать следующие сценарии работы:

1. **Просмотр списка задач**
   * Вывод всех существующих задач из базы данных.
   * Для каждой задачи должно отображаться её название, статус и **название её категории**.

2. **Создание задачи**
   * Форма добавления задачи, содержащая поле выбора категории (выпадающий список).
   * Обработка `POST`-запроса и сохранение задачи в БД.

3. **Редактирование задачи**
   * Страница с формой, предзаполненной текущими данными задачи (включая выбранную категорию).
   * Сохранение изменений в БД.

4. **Удаление задачи**
   * Возможность удалить выбранную задачу по её `id`.

5. *(Дополнительно)* **Работа с категориями**
   * Простая форма для добавления новой категории (чтобы можно было пополнять список категорий прямо из интерфейса).
